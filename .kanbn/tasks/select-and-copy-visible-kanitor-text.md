# Select and copy visible Kanitor text

Allow copying text directly from every explorer view.

- Add configurable selection-mode and copy keybindings.
- Highlight dragged or keyboard-selected visible text without activating rows, squares, or pane dividers.
- Freeze the displayed selection while background readers continue polling.
- Copy Unicode plain text to the system clipboard on macOS, with a terminal clipboard fallback elsewhere.
- Support Projects, Boards, Tasks, Activity, previews, help, and task details.
- Document controls and verify selection, cancellation, clipping, resize behavior, and clipboard failure handling.
